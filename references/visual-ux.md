# 视觉偏好

- 项目现有设计规范优先；文案、间距等明确微调复用现有设计，新页面或需要设计决策时再读取项目 DESIGN.md 等相关规范。个人偏好以本技能 references 为准，不加载已被替代的 `~/.codex/design` 旧副本或旧 Design 仓库链接，不例行联网查更新。
- 默认深化一个方向，用户要求比较才做多方案；UI 任务不自动增加生图、方案确认或过程文档。
- 沿用项目主题和图标体系，变量缺失时在主题层集中补充。后台重信息和操作效率；减少无意义的大标题、空白、嵌套卡片与装饰。
- 设置、配置和编辑默认居中弹窗；长内容内部滚动，标题、关闭入口及底部操作始终可见。尺寸和基础交互复用项目组件。
- 设计覆盖受影响的加载、空数据、错误重试、禁用、提交中与成功反馈；长中文标题、数字、金额和缺图用真实或明确标识的模拟数据检查。
- 布局改动覆盖手机与桌面，宽表格明确滚动或收起策略；表单标签、可见焦点、图标按钮名称及非颜色状态提示保留，尊重减少动态效果偏好。
