# 组件与工具偏好

复用顺序：项目组件与样板 → 已安装组件库 → 最小业务组件。差异优先用组合、参数和变体表达，沿用库的交互行为与主题；单次使用或机械次数不作为抽象依据，同类界面保持布局、间距及响应式一致。

以下偏好仅在可用并兼容项目时应用，已有项目不自动换库：

| 条件 | 选择 |
| --- | --- |
| 新 React 项目尚未选库 | 优先 Astryx；项目样板优先，缺适用样板再选官方模板，沿用主题和比例 |
| 新 Vue 项目 | 优先 shadcn-vue CLI 基础组件再定制；现有 shadcn 项目继续复用 |
| 新布局或整体改版有具体设计问题 | Oil UI Pro；明确微调复用现有设计 |
| 用户要求专项审查或出现质量疑点 | 可用的 web-design-guidelines，仅检查相关范围 |
| 页面与交互验证 | 优先现有 Playwright CLI；需要登录态时用能复用该会话的浏览器工具 |

Astryx 使用项目版本 CLI；已知组件先查 `component <Name> --props`，独立查询批量执行，缺示例再查完整文档。工具不可用则使用项目现有能力，不为执行技能例行安装或升级。
