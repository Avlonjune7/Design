# 页面性能

涉及页面加载、请求、资源或渲染问题时读取；先测瓶颈，再选最小有效改动。

- 首屏：优先关键内容，减少阻塞资源与非必要初始化；非首屏图片延迟加载，关键图片及时加载，图片及占位预留尺寸。
- 资源：按展示尺寸压缩图片，控制字体字重、图标及新增依赖；代码分割由实际加载收益决定。
- 请求：消除重复请求和串行瀑布；缓存、合并及轮询频率以业务一致性为前提，避免展示过期关键数据。
- 渲染：依据测量减少昂贵计算、无效更新和大 DOM；数据规模足够大时才用分页或虚拟列表，动效尊重减少动态效果偏好。
- 验证：前后使用可比较设备与网络，区分首次加载、二次导航和主要交互。必要时用 Performance、Network、Lighthouse 或已有监控定位；不为跑分更换框架、引入基础设施或增加复杂依赖，评分不能替代实际体验。
