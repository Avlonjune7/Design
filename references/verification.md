# 验证偏好

- 相关工具可用且适合项目时，sh/bash 用 ShellCheck，PowerShell 用 PSScriptAnalyzer，GitHub Actions 用 actionlint。缺失工具是否安装由项目要求和具体验证需求决定。
- 浏览器任务开始时按登录态与验证目标选择工具。真实登录态的线上页面操作、表单和接口关联排查优先 BrowserSkill，先读取其技能；本地页面与独立浏览器测试优先 Playwright CLI。用户指定工具时遵循用户要求。首选工具不可用或缺少所需能力时，使用适合的已连接工具并说明实际原因。同一页面由一个工具控制，结束时按对应技能清理本任务会话。
- BrowserSkill 排查聚焦目标弹窗、控件和相关接口字段；按需保存并复用观察结果，用局部查询减少整页重复读取。将已确定且可共用当前上下文的操作批量执行，依赖新观察的操作分步执行。发生页面或人工操作变化后同步状态，执行细节遵循 BrowserSkill 技能。
- 界面缺项或重复时，结合目标区域与相关接口响应定位；滚动问题在实际容器内验证滚轮行为。根据实测结果描述提速，分别记录浏览器、构建、备份与部署的耗时原因。
- UI 局部改动从真实入口查看影响区域，交互改动走到操作结果。涉及布局与响应式时覆盖手机和桌面关键断点，公共组件改动抽查代表性使用页面。新增影响、失败、未解决疑点或用户要求触发扩大验证。
