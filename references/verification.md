# 验证约定

- 按影响完成项目要求的检查；低影响可逆修改不增加只复述实现的测试。改 Shell 用 ShellCheck，改 Actions 用 actionlint；工具不可用时报告相应缺口。
- UI 局部改动查看影响区域，公共组件抽查使用页面，布局与响应式改动覆盖手机和桌面；主要交互从真实入口走到可观察结果。编译通过、评分或保存截图不能替代实际查看与操作。
- 功能与接口改动验证受影响行为，关键业务补必要回归；迁移与格式变更核对兼容、迁移和回滚限制。纯文档核对事实与引用，不运行无关 UI 或构建检查。
- 复用测试环境、预览及浏览器会话。失败先诊断、相关修改后重验；已通过检查仅在相关变化或新疑点出现时重跑。普通工作不自动启动额外评审代理。
- 交付简述改动、验证和实际未验证范围，无需固定标题、额外报告或“无缺口”占位；未测量不声称性能提升比例。
