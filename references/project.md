# 项目约定

- 沿用现有架构与工程风格，复用已有能力，保护用户修改。开发、构建、测试默认当前原生环境；项目明确要求 WSL、容器等环境时依项目执行。
- 优先复用现有服务、登录态与预览，保护共享进程和数据；跨 Windows、WSL、容器或远端时核实连通性。区分本地预览、Mock 与生产结果，正式功能接真实接口。
- 数据库、API、协议或持久化格式改变时，明确已有调用方与数据的兼容、迁移及回滚限制。
- 搜索先定位再读取，独立只读查询批量执行；已核实的信息只在相关变化或疑点出现时重查。文本优先 rg，临时 Python 工具优先 uv/uvx；库文档优先专用 CLI 或 Context7，不足再查官方文档。
- GitHub 用 gh，提交推送用 git；先核实仓库、分支和登录态，推送部署遵循任务授权与项目流程。

## 创建或整理项目规范时

只有用户要求或项目流程需要时才创建/整理 AGENTS.md；已有文件合并补充，不覆盖项目决定。记录实际技术栈、关键入口、工作目录、已核实的运行/验证命令及稳定部署迁移约定，避免复制全局规则、凭据或临时状态。

项目 DESIGN.md 只维护当前组件、主题与布局决定，历史另存。文档跟随相关变更维护；无新决定不新增文档，普通项目工作不自动更新个人规范。
