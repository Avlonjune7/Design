# 项目约定

- Windows 原生开发。额外安装 CLI、开发工具和工具链优先使用 WinGet，支持自选目录时放到 `D:\code\cli\<工具名>`。项目依赖跟随项目，固定路径遵循工具约定，已有安装按用户要求迁移。
- 工具选择和输出控制见 [CLI 与执行效率](cli-efficiency.md)，涉及相关操作时读取。
- 查文档优先已有专用 CLI 或 Context7，按问题读取必要片段，信息足够即停。环境盘点、版本查询和联网更新由实际任务触发。
- Go 本机开发和测试使用 Windows 目标。部署 Debian 时按服务器架构构建 Linux 产物，纯 Go 可交叉编译，CGO 按项目依赖选择工具链。目标平台变量限于构建进程，部署后验证实际运行。
- 仅在要求整理规范时维护项目 AGENTS.md。DESIGN.md 保存当前设计决定，历史另存。交付简述结果、验证与实际缺口，过程文档按任务要求生成。
